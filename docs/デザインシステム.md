# DimiX デザインシステム

2026-11-28 のリニューアルで定義。値の実体は `assets/css/style.css` の先頭 `:root` にある。
ページやサービスを追加するときは、ここにあるトークンとコンポーネントだけを使う。新しい色や影を直接書かない。

## 1. コンセプト
**Healthcare × Technology × Creative**
- Healthcare：清潔な白と淡いラベンダーグレーの背景、安全を表す青緑は「チェック・安心」の印だけに使う
- Technology：ロゴのグラデーション、暗い紺のセクション、整った数字の書体
- Creative：ロゴの「軌道の弧」を背景のグラフィックに使う、非対称のレイアウト、大小のタイル（Bento）

## 2. ロゴから取った要素
| ロゴの要素 | サイトでの使い方 |
|---|---|
| 水色 → 藍 → 青紫のグラデーション | `--brand-gradient`。主要ボタン、見出しの強調語、番号、ブランドのタイル |
| 右下の軌道の弧（D と X を囲む曲線） | 背景グラフィック `.orbit`（同心円＋三日月形の弧＋点）。ファーストビュー・暗いセクション・お問い合わせ帯 |
| X の斜線 | グラデーションの角度（120度） |
| 丸みのある書体 | 英字見出し・数字は Plus Jakarta Sans（幾何学的で丸みがある） |

## 4. 文字
- 日本語：Noto Sans JP（400 / 500 / 700）。英字ラベル・数字：Plus Jakarta Sans（600 / 700 / 800）。Google Fonts から読み込む
- 大きさ：`--fs-display`（トップの見出し）→ `--fs-h1` → `--fs-h2` → `--fs-h3` → 本文 16px → 注記 14px。14px 未満は使わない
- 行間：本文 1.9、見出し 1.4
- 英語の小見出し（`.eyebrow`）は 0.8rem の小さいラベルにとどめ、大きな英語見出しは使わない
- 見出しは「、」「。」ごとに `<span class="ib">` で包み、語の途中で改行しないようにする（変換スクリプトで付けた。手で見出しを書くときも同じ形にする）

## 5. 余白・角丸・影
- 余白は 8px 基準（`--sp-1`〜`--sp-9`）。セクションの上下は `--section-y`（72〜128px）
- 角丸：小 10px／中 16px／大 24px／特大 32px／ボタンは丸（`--r-pill`）
- 影：`--sh-1`（カードの基本）、`--sh-2`（浮かせる）、`--sh-3`（画面の画像など主役）、`--sh-brand`（主要ボタンのホバー）

## 6. コンポーネント
| 名前 | クラス | 使いどころ |
|---|---|---|
| 主要ボタン | `.btn.btn-primary` | 問い合わせなど、そのページで一番してほしい行動。1画面に1つ |
| 補助ボタン | `.btn.btn-outline` | 詳しく見る、料金を見る など |
| 文字リンク | `.text-link` | 文中・タイルの中の移動 |
| ラベル | `.eyebrow` | セクションの見出しの上 |
| 大小のタイル | `.bento` ＋ `.tile.span-6/4/3/2` | 安心材料、サービス紹介 |
| サービスへの入口 | `.service-doors` ＋ `.door` | トップのファーストビュー、会社情報 |
| 番号つきの強み | `.strengths` ＋ `.strength` | 暗いセクション |
| 進め方 | `.flow3` | 番号と線でつなぐ横並び |
| 背景グラフィック | `.orbit`（build 用スクリプトの `orbit()` で生成） | ファーストビュー・暗いセクション |
| ページ内目次 | `.page-nav` | 長いサービスページの上部 |
| スマホ下部の固定ボタン | `.mobile-cta` | トップ・サービスページ。ファーストビューを過ぎたら出る |

## 7. アイコン
- `assets/img/icons.svg` の線のアイコン（線幅 1.8px・角丸）だけを使う
- 背景つきで置くときは `.icon-wrap`（角丸 14px、淡いブランド色）。NOTYCE は `.icon-wrap.ny`、安全・確認は `.icon-wrap.ok`

## 8. 動き
- `.reveal` を付けた要素は、画面に入ったときにふわっと表示（0.7秒）。`data-delay="1〜3"` で少しずつずらす
- ボタン・カードはホバーで少し浮く。ファーストビューの弧はゆっくり回る（120秒で1周）
- `prefers-reduced-motion: reduce` の端末では、すべての動きを止める
- JS が動かない環境でも、すべての内容とメニューが表示される

## 9. 掲載ルール（デザイン以外で守ること）
- NOTYCE の画面はデモ用の架空データ。近くに必ず「デモ用の架空データ」の注記を付け、導入実績・事例として扱わない
