# 公開手順（Canva → GitHub Pages、URL は dxdimix.com のまま）

作業は 4 段階です。1〜3 はサイトが止まらない作業で、4 の DNS 切り替えの瞬間だけ表示先が変わります。

## 1. GitHub にリポジトリを作る
1. https://github.com/new を開く（dxdimix アカウントでログイン）
2. Repository name：`dxdimix-website`
3. Public を選ぶ（無料プランの GitHub Pages は Public リポジトリのみ）
4. 「Add a README」などのチェックは全部外したまま「Create repository」
5. Claude にリポジトリを作ったことを伝える → Claude がファイル一式を push する

## 2. GitHub Pages を有効にする
1. リポジトリ → Settings → Pages
2. Source：「Deploy from a branch」
3. Branch：`main`、フォルダ：`/ (root)` → Save
4. Custom domain 欄に `dxdimix.com` が入っていることを確認（`CNAME` ファイルから自動で入る）
5. この時点では `https://dxdimix.github.io/dxdimix-website/` で仮表示を確認できる
   （独自ドメイン前提のパスのため、一部のリンクがずれることがある。本番ドメインでは正常に動く）

## 3. ドメインの管理場所を確認する
Google Workspace で取得したドメインは、多くの場合 Squarespace Domains に移っています。

1. https://admin.google.com にログイン
2. 「アカウント」→「ドメイン」→「ドメインの管理」
3. dxdimix.com の横に「詳細を表示」や「DNS の管理」があれば、そこから移動した先が管理場所
4. 見つからない場合は https://account.squarespace.com/domains に Google アカウントでログインして確認

## 4. DNS を切り替える（Canva → GitHub Pages）

### 触ってはいけない設定
**MX レコード、`google-site-verification` などの TXT レコードは絶対に消さない・変えない。**
消すと Gmail（会社メール）が届かなくなります。変えるのは下の A / CNAME だけです。

### 変更する設定
現在 Canva 向けに入っている `@`（dxdimix.com 本体）と `www` の A レコード・CNAME レコードを削除し、次を登録します。

| 種類 | ホスト名 | 値 |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | dxdimix.github.io. |

（任意）IPv6 用の AAAA レコード：`2606:50c0:8000::153` / `8001::153` / `8002::153` / `8003::153`

### 切り替え後
1. 反映まで数分〜最大 48 時間。多くは 1 時間以内
2. GitHub → Settings → Pages で「DNS check successful」になったら、「Enforce HTTPS」にチェック
   （証明書の発行に最大 24 時間かかることがある）
3. https://dxdimix.com と https://www.dxdimix.com の両方が新サイトになったことを確認
4. 確認できたら、Canva 側で独自ドメインの接続を解除する（Canva の サイト → ドメイン設定）

## 5. （推奨）GitHub でドメインを認証する
他人のリポジトリに dxdimix.com を乗っ取られるのを防ぐ設定です。
1. GitHub 右上アイコン → Settings → Pages → 「Add a domain」に `dxdimix.com`
2. 表示される TXT レコード（`_github-pages-challenge-dxdimix`）を DNS に追加
3. 「Verify」を押す
